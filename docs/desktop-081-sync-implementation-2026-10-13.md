# torto 0.8.1 移动端同步实施记录

本轮以桌面已提交的 `50cb658`（v0.8.1）为参照。实施前的 App 本地代码已提交为 `95fd42f` 并推送到 `origin/main`；后续同步实现与本记录一同纳入本轮代码提交。桌面的未提交代码没有作为同步依据，也未被修改。用户追加要求同时完成所有剩余项，因此本轮包含此前确认的六项，以及阅读聊天、图片附件、文字图片正文排版和手机本地 PDF 重排生成。App 版本保持 `0.7.1+7222`。

## 阅读与排版

- 章节编号和标题在统一版式中组合显示，保留各自的源节点与锚点。双语标题可复用数字或罗马数字编号；只收到部分译文时保留已收到内容。
- 括号内的中英文图表引用与书目引用共享序号，仅匹配完整引用；含说明正文的括号不折叠。图表预览优先匹配本章，跨章仅接受唯一目标，支持表格、图片和说明。
- 普通段落恢复列表支持圈号、全角括号、小图片标记、连续编号和缩进嵌套。编号重新起算形成新组；参考文献、注释、导航、年份及弱破折号受到保护。源文字与标记图片保留，统一版式隐藏重复标记。
- 图片尺寸遵循所在容器宽度；明确的 `aria-describedby` 可关联非相邻图注，保留中间正文。面包屑只在明确导航结构中移除，不吞掉含链接的普通段落。
- 未列入目录的连续阅读单元可并入前一章节。重复摘引按原文或长摘引中的一次短修改判断；标题、注释、非线性 spine 等保持独立。合并保留原始 spine、节点、片段链接和源偏移，章节缓存有上限。
- 冒号后仅一个完整句子时连续排版，继续保护 URL、时间、比例、缩写和成对标点；作者换行保留。
- ruby 支持上方、下方及表格内注音，复制、搜索和偏移按基础正文计算。统一版式图注只突出编号，未明确对齐的表格按起始方向对齐。
- 整章 Notes 目标中的小号、上标链接可识别脚注；片段目录不误判整章。脚注按正文来源排序，支持循环、全文复制及媒体预览。
- 专注模式提供持久化的“突出当前内容”和“周边淡化”，当前块的关联标题保持清晰。
- 书架依据最近阅读活动显示“继续阅读”标记，沿用已有排序和准确位置恢复。

## 图片文字、翻译与公式

图片识别直接检查原图，响应支持 `recognized_text`、`unreadable_text`、`text` 和 `literal`。本地校验、有效缓存和有限重试保留，不确定结果继续显示原图。

识别文字可用于行内及独立图片的正文排版、选择、复制、搜索和翻译。普通文字支持替换与双语模式，代码和字符示例保持原样。双击文字仍可查看原图。识别文字属于显示层：不增加原书字符偏移，不改变原图锚点；多页长文字以显示进度辅助恢复位置，搜索命中可定位到对应显示页。

行内图片翻译使用明确身份标记，拒绝缺失、重复、额外及变形标记。文字图片使用成对标记并保留原图身份；历史译文仍有兼容恢复。合并章节中的语义识别与翻译使用包含 spine 的节点身份，避免重复节点名冲突。

公式先计算排版尺寸，进入当前页面和视口后才栅格化。渲染分辨率受设备像素比、单图像素上限和可见纹理缓存预算约束；离开可见区域的纹理可回收，公式尺寸与阅读锚点保持稳定。媒体预览拥有独立资源，关闭时释放。

PDF 元数据与目录发现使用独立思考等级。连接失败、超时和指定临时 HTTP 错误最多尝试三次，受取消、总期限与请求预算限制；鉴权错误不会重试。

## 阅读聊天与附件

阅读聊天在当前阅读页中展开：手机使用底部面板，较宽窗口使用侧栏，阅读内容同步调整可用空间。参考内容可跳回正文，关闭面板恢复阅读；窄屏和键盘弹出场景有覆盖测试。

聊天可选择多张本地图片，显示、移除并放大预览附件。图片统一规范化并按散列保存，历史消息持久化附件元数据；恢复历史后仍可参与多模态请求。每张图片、解码像素、请求图片数量及总体积均有限制，过旧图片超出上下文预算时保留省略提示。

工具执行进度可折叠，步骤数量有上限；历史回复保存并恢复工具步骤。测试使用受控多模态请求与工具响应，没有调用真实付费模型。

## PDF 归档消费与本地生成

原生 PDF 归档兼容桌面格式版本 12 至 14，直接消费桌面 Reading IR 和真实序列化 URL 结构。连续存储块合并为阅读章节，保留源身份。归档准备和章节读取在后台 isolate 中进行，入口检查身份、路径、重复条目、资源、页目标、大小和解压校验；不可变散列缓存使已打开的旧代内容继续有效。

阅读设置可选择原生文字、OCR 或原始 PDF，先返回对应物理页并保存位置，重开应用来源。明确的来源偏好受到保留；原生结果失效时保留原版。原始 PDF 解析和渲染继续使用纯 Dart。

新增“本地 PDF 重排”入口，可查看进度、取消并重新生成。手机端在后台提取文字，按已有列与段落顺序重排、处理软连字符，结合字号判断简单标题，并将原目录定位到页锚点。手机算法采用独立的稳定源 ID，避免与桌面生成算法混淆。

手机生成器采用保守回退：扫描页、无法可靠提取文字的页面、旋转文字和包含图形对象的页面保存原页图像。复杂图表、表格和脚注的识别质量没有宣称与桌面一致。逐字源位置写入桌面兼容的压缩几何侧文件；本轮没有新增原页逐字标注界面。

生成结果使用版本 14 归档和待上传元数据，资源大小与归档总体积有限制；文件散列校验防止输入 PDF 在处理中被替换。归档与元数据成对发布，写入日志支持中断恢复和失败回滚，本地磁盘变更互斥。

同步保留待上传的手机结果。上传使用不可变快照；上传期间重新生成时，仅确认已上传的那一代，并将新代的基准更新为刚发布结果。远程基准冲突保留本地文件并报告错误，下载后也再次检查本地待上传状态。

远程成对发布使用 WebDAV 集合锁和条件写入，避免并发覆盖。服务器必须支持 `LOCK`；不支持时保留本地结果并报错。现有测试验证锁、条件写入、冲突及下载保护，没有验证实际服务器兼容性。

## Gitee 镜像

同步流程支持预发布版本，Android 各 ABI 复用一次 Actions 产物提取，并对散列验证后的下载缓存复用。失效产物回退到 Release 下载。网络失败提供传输诊断，日志隐藏令牌；Gitee 与 GitHub 使用各自鉴权方式。工作流授予读取 Actions 的权限，整体期限调整为 360 分钟，大文件传输期限为一小时。没有执行实际发布。
