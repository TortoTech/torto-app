# 移动端清晰度与专注滑动实施记录

本轮包含前一轮已修正的四个搜索服务设置，以及图片和专注滑动方案。版本仍为 0.7.1，构建号提高到 7110；arm64 APK 最终 Android 版本码为 9110，以覆盖此前手机上的 9100。没有提交、推送或发布。

## 图片

- EPUB、MOBI/AZW、FB2、CHM/HTML、CBZ 使用原始资源尺寸排版，不再按整章图片数分摊低清纹理。PNG/JPEG/GIF 优先读尺寸头；其他可解码格式使用图像描述符，不提前解码整章像素。
- PDF 从纯 Dart 页面模型取得尺寸，仅按视口需求栅格化，继续使用按分辨率区分的磁盘缓存。PDF 识别预览和阅读资源独立。
- 视口与相邻逻辑页优先加载，按目标区域和设备像素比请求分辨率；单个阅读纹理限制约 4 Mi 像素、最长边 8192。离屏纹理按 48 MiB 预算淘汰，并在远离章节时释放。可见纹理受保护，编码资源和 PDF 库的缓存另有自身预算，不能把此数字当作整个进程的内存上限。
- 页面及行内图片明确使用缩放采样。升级纹理不触发重排，排版、链接、选区和源锚点保持稳定。
- 双击块图片打开可缩放预览，重新从源解码，预览独立持有和释放纹理；上限约 16 Mi 像素。低分辨率原图不会生成不存在的细节，超大图也不会无限解码。行内小图片目前没有单独放大入口。

50 图 EPUB 测试确认：可见图片按 3 倍屏幕精度解码，宽度超过 900 px，而不是旧预算约 354 px；离屏图片未提前解码，提升精度后原页面及图像矩形不变，预览保留 1800×1200 原始尺寸。真实 EPUB 和 AZW3 样本继续覆盖图片解码及绘制；行内引用和表格图片覆盖章节淘汰后可重新加载。

## 专注滑动

- 每个逻辑页仍为一个小节；左右滑动时两个小节表面同步平移，切换后保留访问状态。上下滑动一次只推进一个激活块，或长块内一个阅读窗口。
- 取消整小节的自由惯性。超过 36 dp 或满足快速滑动阈值后提交一步，否则回到原位置；采用 160–360 ms 缓入缓出停靠动画，触摸可中断。
- 长段落、表格、列表和长图先在块内推进，中央阅读窗口最多 240 dp，读取到末端后下一次手势才换块；反向进入长块从末端开始。图像和可完整阅读的图注有可逆停靠点。
- 点击其他正文块会激活并定位；标题不变暗，不激活正文。首末留白允许内容停靠，首次进入保留前置标题。
- 动画期间保留明确激活块，不用视口位置重新猜测。短块进度保存激活源锚点，长块保存可见源位置；重排、模式切换、重开均有回归覆盖。
- 手势只驱动一个方向；选择、打开助手/设置、点击引用或图片预览会停止运动。小节首尾竖滑仅反馈边界，不跨小节。
