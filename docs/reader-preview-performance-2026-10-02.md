# 图片预览、引用弹窗与缓存书籍性能优化

最终构建 `0.7.1+7150`，arm64 Android 版本码 **9150**。本轮没有提交或发布。

已通过无线 ADB 覆盖安装到手机并成功冷启动。正式签名及手机上实际 APK 的文件散列已核验；首次安装时间保持 `2026-08-30 08:47:45`，没有卸载或清空数据。最终 APK 的代码检查确认自动诊断和临时导出调用均未包含在发布代码中。部署清单为工作区 `output/torto-app-071/build-manifest-9150.json`，无线 ADB 服务保持运行。

## 预览和标识

- 图片和公式预览共用透明内容层和蒙层，移除 Dialog/AlertDialog 外壳及关闭按钮。点击外围或蒙层关闭，点击内容保留预览；支持拖动和缩放。
- 公式预览与公式图片使用白色背景，公式文字使用黑色；普通图片保留自身背景。
- 脚注及引用标识使用正文同一套蓝色。标识在首行行高槽内居中，并跟随系统文字缩放，避免多行脚注将标识移到整段中部。
- 引用弹出内容按桌面 `FocusFootnote.popup_text` 规则去掉最外层的 `()`、`（）`、`[]` 或 `［］`。原始文本、脚注普通括号、引用编号和源定位均保持原状。

## 实际缓存书籍

测试的是手机 Torto 私有缓存中的《Computational models of reading》，不是另一本同名文件或模拟书：9,587,324 字节，共 21 个章节，SHA-256 为 `ea08a774131595c5b154e15d83f1e48bb39e568a9e4411eff5fe9751333d418c`。

应用自身在私有缓存中读取目标书，使用一次性编译开关执行诊断。为完整对照解析结果，临时通过应用导出该文件到本机测试，随后删除手机上的临时导出副本，并移除原生导出入口。原缓存文件和阅读位置没有修改。最终普通构建没有启用自动诊断开关。

诊断发现大章节反复扫描整份 CSS 规则，且对同一个 XML 元素重复计算级联样式。现在按选择器必需的 ID、类名或标签建立候选索引，仅匹配可能命中的规则；解析期间缓存元素的级联样式。新增样式会清空元素缓存；样式优先级、来源顺序、行内样式和继承规则保留。

同一手机 `23013RK75C`、同一缓存文件，前后各一轮，解析阶段结果如下。索引是内部 XHTML 单元序号，不是书中自然章节号。

| 范围 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 可对比的 18 个单元，解析耗时合计 | 14,361 ms | 1,800 ms |
| 索引 10，293,392 个字符 | 2,647 ms | 393 ms |
| 索引 14，163,987 个字符 | 2,856 ms | 245 ms |

可对比单元的解析总耗时约减少 **87%**，优化后完成全部 21 个单元。开书测量为 432/210 ms，但它受系统缓存和启动状态影响，不能单独归因于本次 CSS 优化。原始记录在工作区 `output/reading-performance/phone-baseline.log` 和 `phone-optimized-1.log`。

长章节的排版仍约 2–3 秒：固定视口 `393×780` 下，索引 10 普通模式 422 页、约 3.23 秒，专注模式约 3.16 秒；索引 13 约 2.45 秒。排版和 HTML 解析是独立阶段，本轮没有将排版耗时计为解析收益。上述是固定设备和样本的测量，不是所有书籍或总开书时间的收益承诺。
