## Feature

- Highlight passages, add annotations, and search within books, with highlights and annotations shared with the desktop app through cloud sync.
- Track reading time and history automatically, view statistics from Me, and mark books as finished at the end.
- Choose available system fonts or the bundled Literata and LXGW WenKai fonts, with separate font combinations for CJK and other books and quick font and size controls while reading.
- Load an AI provider's available models, select multiple models, and configure the translation model's reasoning effort.

## Improvement

- Improve paragraph spacing, line breaks, headings, lists, quotations, captions, and inline formulas for a more consistent reading experience.
- Select whole paragraphs in translation mode and attach highlights and annotations to their original text.
- Improve translation wording and translate linked footnotes while keeping note definitions out of the main reading flow.
- Simplify the reading toolbar and make text-selection actions more compact.

## Fix

- Correct superscript and subscript positioning in body text and tables.
- Apply the translated language's indentation and font choices instead of the original book's defaults.
- Resume translation for the current chapter after an earlier request finishes, without requiring another page turn.
- Fix reading-statistics synchronization failures and uneven text-selection highlights.
- Prevent a light background from flashing when opening a book in dark mode.
