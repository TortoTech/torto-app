# 移动端稳定性与排版同步实施记录

本次按用户确认实施 P0/P1；AI 排版识别与专注模式均未加入。保留并兼容工作区已有脚注、引用、统计与翻译提示词改动，不提交或发布版本。

## 稳定性

- PDF 的解析、目录与元数据读取移至 isolate；页面解释和图像预解码使用现有 PDF 库的长期 worker，池大小为 1，命令缓存最多 3 页、解码像素预算 24 MiB。界面线程仍负责 Canvas 回放和最终光栅化，不声称全部 PDF 工作都已移出界面线程。
- worker 返回失败时报告页面错误，不在界面线程重复执行同一解释任务。部分现有库无法后台处理的 PDF 页面可能因此显示错误；保留内容完整性，不输出截断的绘制指令。封面使用相同后台路径。退出阅读释放 worker。
- EPUB 首次开书已有后台解析；现在后续章节也通过长期 worker 解析，重复请求合并，主侧和 worker 各保留最多 6 个章节结果，退出时停止 worker。worker 持有一份档案快照，因此内存并非零成本，需要实机监测大文件峰值。
- 大章节的翻译输入构建、结果校验和内容组合移至 isolate；缓存检查修订号和显示模式，防止旧结果污染新缓存。小章节保持轻量直接处理。
- 分页在块间检查取消，已暂停的任务也能因销毁或代次变化退出，释放已生成 Paragraph。仍沿用整章分页，尚未改成增量分页或跨重排复用 Paragraph，以免改变锚点和页面所有权。
- 整章图片改为串行解码，新图片按章节数量分配最长边，目标解码像素预算 24 MiB/批，最大边长 2048；不将此预算等同于应用总内存上限。
- 超过 4096 UTF-16 单元的段落不进入昂贵的自定义全段测量；优化器另设 4096 cluster / 100000 候选上限。超限使用基础排版，保留全文和源映射；极端长段落的断词/精细两端对齐可能有所不同。

## 排版与内容恢复

- 支持字号关键词、绝对 px/pt、父级 em/% 和根级 rem。IR 单独保留关键词意图，统一模式使用关键词字号而不与标题/引用角色字号相乘；显式长度覆盖继承关键词。
- 复查后翻译改用桌面相同的 `<torto-size scale="...">` 关键词字号标记；仍可读取第一轮的编号标记。新请求严格校验字号；旧无标记译文仅在整段字号一致时保留字号，混合字号不推断范围。绝对数值字号按桌面策略处理，不额外发送移动端私有标记。
- 多段图注按整体行数决定对齐，单行居中，多行统一靠前；图注内联图片传入资源尺寸。统一模式下引用和署名保持直立，原书模式保留作者样式。
- XHTML 正常路径保持 XML 解析；失败章节使用 HTML5 恢复遗漏闭合和重复属性等问题，保留正文、链接、锚点及 SVG/MathML 的名称。仅章节走 HTML5，OPF/NCX/FB2 元数据保持原路径。
- 内容解析设 2 MiB 字符、50000 标签、128 层深度及恢复后 100000 节点上限；拒绝实体声明和内部 DTD 子集。超限章节仍按现有容错路径为空，不能把“任何损坏书籍都能恢复”作为承诺。

## 诊断

- 应用私有目录 `diagnostics/reader.log` 异步记录，单份 1 MiB，最多 3 份，待写队列最多 128 项。包含应用版本、PDF 分阶段耗时、章节解析/重排、较慢帧和事件循环延迟；不写正文、译文、请求内容或异常消息。
- Android 启动时读取本应用最近 8 次退出信息，尽力保存系统允许访问的 trace；最多 3 份，每份前 128 KiB。原生采集在专用后台线程执行。
- 设置页新增“导出诊断日志”，通过系统保存文件界面导出本地诊断与 ANR trace，不自动上传。
- release 构建保留 `build/symbols/7016` 对应符号，供后续精确还原地址。

## 验证与边界

新增回归覆盖字号继承和翻译映射、图注整体对齐、引用样式、损坏 XHTML、外来命名空间、暂停后取消分页、长段落全文保留、日志轮转、EPUB worker 响应和大章节翻译锚点。PDF 测试逐像素比较后台与原渲染路径输出。

最终验证：完整 Flutter 测试 378 项通过、1 项跳过；`dart analyze lib test` 无问题；arm64 release 构建成功（命令退出码 0）。APK `build/app/outputs/flutter-apk/torto-0.5.0-7016-arm64-signed.apk` 的最终 versionCode 为 7016，versionName 为 0.5.0，签名 SHA-256 与仓库记录的 Torto Android Release 证书一致。安装包及符号的散列、检查输出保留在工作区 `output/torto-mobile-audit-20260922/`。本轮未安装到手机，未提交 Git；无线 ADB 保持连接。

这次改动消除了已识别的界面线程重计算路径，并增强诊断，但原始 ANR 尚无匹配符号和用户问题书籍的复现，不能宣称那三次 ANR 的具体根因已经证实或手机卡死已完全解决。20 次实机重复操作、触摸 p95 和内存峰值验收仍需实际问题书籍验证。桌面 AI 排版、全增量分页、替换 PDF 引擎均不在本次交付中。

## 实机后续

用户授权安装后，7017 实测发现 worker 图像引用回绑遗漏造成扫描 PDF 正文层丢失，以及同步缓存超过 Android CursorWindow 限制。两项均已修复，7018 已保留数据部署并完成同书复测；详见 `android-device-verification-2026-09-22.md`。该阶段交付版本为 7018，7016/7017 仅保留作历史定位。

用户随后要求继续改善 PDF 性能，并明确保持纯 Dart。当前交付已更新为 7020，包含 JPEG 2000 热点循环优化、下一页优先预读及无损磁盘页面缓存；原生实验没有部署。实机对比见 `reader-performance.md` 的 build 7020 小节。
